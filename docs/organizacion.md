# Organización y seguimiento

Esta página recoge quién hace cada cosa, en qué estado está y dónde está la evidencia. Se actualiza **a mano** cuando el grupo avanza: que exista un archivo `.md` no significa que la tarea esté validada.

## Estados editoriales

| Estado | Significado |
|---|---|
| <span class="estado estado--pendiente">Pendiente</span> | Todavía no se ha empezado o no hay documento. |
| <span class="estado estado--desarrollo">En desarrollo</span> | Hay un borrador en elaboración. |
| <span class="estado estado--revision">En revisión</span> | Otra persona del grupo lo está comprobando. |
| <span class="estado estado--validado">Validado</span> | Revisado, con evidencias y aceptado por el revisor. |
